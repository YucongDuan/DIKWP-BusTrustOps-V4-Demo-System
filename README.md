# DIKWP BusTrustOps V4 Demo System

## What it is
A standalone browser-based simulation console for DIKWP public transport semantic governance.
It demonstrates Evidence Ledger, DIKWP SemanticClosure, Action Ticket, role governance, multi-agent coordination, and white-box evaluation.

## What it is not
It is not a production dispatch system, not an autonomous vehicle control system, not a charger control system, and not a public release system.

## How to run
Open `index.html` or `dikwp_bustrustops_v4_demo.html` in a browser. No server, no API, no external dependency.

## Demo modes
- Demo-0 synthetic data
- Demo-1 desensitized SOP/case customization
- Demo-2 CSV/Excel offline replay
- Demo-3 read-only sandbox interface

## Suggested demo order
1. Select `自动驾驶群体异常`
2. Switch roles from leadership to safety, IT, regulator and DIKWP expert
3. Open Evidence Ledger, DIKWP closure, Action Ticket, Multi-agent, Scorecard
4. Toggle missing GPS / SOP conflict / high-risk escalation
5. Export JSON
